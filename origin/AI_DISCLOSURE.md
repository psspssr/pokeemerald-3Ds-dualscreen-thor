# AI use disclosure

AI-assisted development tools have been used during the development of this
project for implementation, debugging, refactoring, testing and documentation.

AI-generated or AI-assisted changes are reviewed and tested by the maintainer
before being accepted into the project. The repository intentionally does not
include raw prompts, chat transcripts, temporary agent worktrees or other
editor/runtime state because those files are development artifacts rather than
project source.

Bug reports and contributions are evaluated based on their technical quality,
regardless of whether AI-assisted tooling was used.
