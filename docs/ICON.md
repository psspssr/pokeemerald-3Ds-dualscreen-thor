# Project icon

An emerald sky-serpent frames two bright screen-shaped gemstones. Bold planes,
open space and restrained gold accents keep the mark readable at launcher size.
It is shared by the Android launcher, README and website.

The transparent [master artwork](../android/app/src/main/res/drawable-nodpi/ic_launcher_art.png)
is bundled locally. Android adds a dark green background and a 20 dp inset to
protect the artwork under adaptive icon masks; themed icons use its silhouette.
No image service is required by the app.

The artwork was generated with the built-in imagegen tool. It is an unofficial
project emblem, not an official Pokémon or AYN logo. See [notices](../NOTICE.md).
